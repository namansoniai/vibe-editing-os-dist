## Engine built-ins pass 2026-10-07
- Now built-in: T-WHIP blur is a footage radial blur centred on the device point (`timeline.blur` radial, f−2…f+1, the measured 3 f) + a `flash` transition at the measured 28 % peak (4 f up, 3 f down; v02 @ 10.6, v03 @ 2.5); the incoming land is a 14 px defocus decay over 3 f. The drawn 56-streak radial pass and the white-rect z11 scene are gone. POV scenes are z1 plates so the footage blur reaches them.
- Now built-in: zoom / roll about the device: Z-1 `zoom-through` (1.0 → 1.6, 7 f, `ease: "in"`) and Z-5 roll take `p.origin` = the device point (they zoomed about the face before).
- Now built-in: T-WHIP-S and T-WHIP-L are `whip` transitions (diagonal 60°, ≈ 620 px/f, 7 f; horizontal 160 px/f, 6 f, v02 @ 1.30, 5.27, 24.37, 29.73); the linear whip's −30 % luma is a dark `fx.flash` under the captions. The hand-drawn streak passes are gone.
- Now built-in: the bubble drifts with the footage (`follow_footage: true` on a front scene; it was ≤ 2 px/f written by hand, v01 @ 5.4–13.8).
- Now built-in: the ring sweep / tap ripple follow a moving device through `veos track` + `anchor {track, scale_with, lost: "fade"}` (v02 hook, hand-held); fallback = the static box on a still device, else skip. `anchors.mode` is now `track`.
- New option: P-11 3D device slab (`VEOS.fx.three` kind `device` with a still screenshot) when there is no device footage; the 2D drawn phone stays for recordings.
